# RSB Metrology Economic Impact Reporter 📊

## Overview
This application is a specialized tool developed for the **Rwanda Standards Board (RSB)** Metrology Division. It quantifies the economic value of laboratory services, specifically focusing on the **Dosimetry Lab** pilot. 

The tool translates technical calibration data into **GDP-linked metrics** to demonstrate value to RSB Management and international stakeholders like the World Bank.

## Key Features
* **Economic Formulas:** Calculates Domestic Value Retention (DVR), Infrastructure Criticality, and Export Enablement.
* **Visualizations:** Generates bar charts for sectoral impact and line charts for growth momentum.
* **PDF Export:** Generates a formal Technical Report for distribution.
